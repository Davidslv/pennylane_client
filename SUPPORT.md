# Support

## Where to get help

1. [README.md](README.md) for installation, usage, the public API and what is Experimental.
2. [docs/getting-started.md](docs/getting-started.md) for a first call, and [docs/how-to.md](docs/how-to.md) for recipes by task.
3. [docs/architecture.md](docs/architecture.md) for how the gem works inside, including its known limits.
4. [GitHub Issues](https://github.com/Davidslv/pennylane_client/issues) for questions, bugs and feature requests. Include the gem version, the Ruby version, the operation or named method, and the error class and message. Never paste a token.

For security problems, see [SECURITY.md](SECURITY.md). Do not open a public issue.

## Scope

Support covers the gem: its API, its behaviour and bugs in its code. It does not cover Pennylane's service, accounts, plans or API access (contact Pennylane for those), nor general Ruby help. The gem is unofficial and not affiliated with Pennylane.

## Expectations

One maintainer, spare time, **no SLA**. Issues are answered when time allows, which may be days or longer. Minimal reproductions get answered fastest.

# Support

## Where to get help

1. [README.md](README.md) for installation and usage.
2. [docs/](docs/) for detail: getting started, architecture, how-to recipes.
3. [GitHub Issues](https://github.com/Davidslv/pennylane_client/issues) for questions, bugs and feature requests.

For security problems, see [SECURITY.md](SECURITY.md). Do not open a public issue.

## Scope

Support covers the gem: its API, its behaviour and bugs in its code. It does not cover Pennylane's service, accounts, plans or API access (contact Pennylane for those), nor general Ruby help.

## Expectations

One maintainer, spare time, **no SLA**. Issues are answered when time allows, which may be days or longer. Minimal reproductions get answered fastest.

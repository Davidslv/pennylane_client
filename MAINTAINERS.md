## Becoming a maintainer

There is no formal application process. The path is sustained, quality
contributions over time: well-tested pull requests, thoughtful issue triage and
review comments, and demonstrated care for the project's principles (zero
runtime dependencies, honest documentation, the clean-room rule, a test suite that never touches the
live API).

When someone has shown that pattern consistently, the current maintainer may
offer commit access. If the maintainer group grows, [GOVERNANCE.md](GOVERNANCE.md)
will be updated to reflect shared decision-making.

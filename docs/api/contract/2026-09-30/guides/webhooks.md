# Webhooks

Set up webhook subscriptions to get notified of events in real time

<Callout icon="⚠️" theme="warn">
  ### The webhooks feature is in Beta. We recommend falling back on changelog endpoints during this phase.
</Callout>

<br />

Webhooks let your integration receive real-time notifications when something changes in a Pennylane company — for example, a dms file is created or a customer invoice e-invoicing status changes.

Instead of polling our API, you register an HTTPS endpoint and Pennylane sends it an HTTP `POST` whenever a subscribed event occurs.

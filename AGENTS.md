# AGENTS.md

Instructions for AI agents (and humans) working in this repository.

## The gate

`bundle exec rake` must stay green. It runs the Minitest suite, RuboCop and `rbs validate`. The suite stubs all HTTP with WebMock and never reaches Pennylane.

- Test first. Every behaviour change starts with a failing test.
- New HTTP interactions get WebMock stubs, never live calls.
- Use Ruby 4.0.7 locally (`.ruby-version`); CI covers 3.3, 3.4 and 4.0.

## Hard rules

1. **Clean room.** Build only from Pennylane's public documentation (pennylane.readme.io) and observed sandbox behaviour. Never read, copy or adapt the source, README or tests of any other Pennylane API client in any language, and never search for them. When the docs contradict each other, the sandbox settles it; record the choice and the reason.
2. **Zero runtime dependencies.** Standard library only. `logger`, `base64` and `bigdecimal` are bundled gems now: do not require them from `lib/`.
3. **Never log or expose tokens.** Not in logs, `inspect`, exceptions or the `on_request` event.
4. **Never retry side effects.** POST, PUT and DELETE are retried only after a 429 or on explicit opt-in (proposal 0001, D5).
5. **Generated files are never hand-edited.** The contract snapshot, `lib/pennylane_client/operations.rb` and `docs/api/CHECKLIST.md` (all planned, Epic #1) are regenerated by their rake tasks.
6. **No metaprogramming.** No `define_method`, no `method_missing`. Public methods are written by hand.
7. **Never load-test Pennylane.** Load and stress tests run against `FakePennylane` (planned, Epic #1) only.

## Conventions

- One concern per commit, imperative subject, body explains why.
- Branch `<issue-number>-kebab-description`; PR and commit titles `[#<issue-number>] Description`.
- Domain language is in `CONTEXT.md`. Say Operation, not endpoint. Registered and Named have precise meanings.
- Design decisions live in `proposals/`. The current plan is proposal 0001 and Epic #1.
- Public behaviour changes update `README.md` and `docs/` in the same change.
